# FloraMark AI 🌲
Offline Vision Assistant for Hikers & Trail Guides built for Hacktoberfest Week 2 (Side Hustle).

## Why Open Innovation Matters
Commercial cloud vision APIs fail when hikers lose cellular connection in remote wilderness areas. FloraMark AI downloads open-weight vision models (Moondream2) directly into browser WebGPU memory, enabling 100% offline identification of flora, fauna, and trail hazards with zero API costs.
